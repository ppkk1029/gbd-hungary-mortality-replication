# 01｜原文 Figure 1：主要死因占全部死亡的比例

## 原文做什么？
将九类 ICD 主要死因分别计算占**全部死亡人数**的比例，其余归为 `All others`，绘制堆积面积图。

## GBD 对应处理
使用 Level 2 的 19 类原生死因，其中按训练期（1980–2015 年）累计死亡人数选取前九类作为展示组，其余十类合并为 `All other causes`。**这九类不等同于原文九个 ICD 章节。**

分子：每年某类死因在 60–89 岁、男女合计的死亡人数。
分母：同年 Level 1 三大类的死亡人数合计，经逐年龄、逐性别核对等于十九类 Level 2 之和。

计算公式：`share[t,c]=100 × D[t,c]/D_all[t]`。

## 如何运行
1. 将两个原始下载 CSV 置于 `data/raw/`，名称见 [00 章](../00_data/README.md)。
2. 先运行 [Level 1 / Level 2 核验](../00_data/check_level1_level2.R)。
3. 再运行 [run.R](run.R)。程序依次筛选 Number、`aggregate()` 汇总、`xtabs()` 转矩阵、计算 `All other causes` 和占比，再用 `polygon()` 画 Figure 1 同类型堆积面积图。

结果保存于 `outputs/01_figure1/`：
- `figure1_shares.csv`：各年九类和其他类别占比；
- `figure1_gbd.png`：面积图；
- `top9_coverage.csv`：九类的逐年覆盖率；
- `train_cause_ranking.csv`：训练期九类选择依据。

## 已用真实 CSV 独立计算出的结果
| 年份 | 全部死亡人数 | 训练期排名前九类占比 |
| --- | ---: | ---: |
| 1980 | 104,388.45 | 97.80% |
| 2019 | 99,182.03 | **97.76%** |
| 2020 | 108,193.79 | 97.86% |
| 2021 | 119,215.70 | 98.00% |
| 2023 | 97,357.57 | 97.47% |

结果已通过 Python 对原始 CSV 的独立核验；本次 Github 上传的 R 脚本还未在 RStudio 环境实际执行测试。

## 如何对照原文？
原文报告 2019 年九类 ICD 死因占比约 95%，2021 年因疫情等分类变化下降。这里的 GBD 九类占比分别为 97.76% 和 98.00%。**这个差异不能仅解释为模型优劣**：GBD 死因归类不同、人口不含 90+、资料来源也不同。后续重点研究原文图中不同死因相对份额的变化，并如实记录分类差异。

这一节是描述性统计，不是死亡率预测，也尚未进行 DTW。
