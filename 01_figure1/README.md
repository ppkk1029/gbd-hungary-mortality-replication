# 01｜Figure 1：死因占全部死亡人数的比例（原文 §3.1）

## 原文做了什么
原文 Figure 1 展示 1970–2021 年九类 ICD 死因及 All others 占全部死亡人数的比例，是**堆积面积图**。没有单独的七类男女折线图，本仓库也不添加。

## 计算思路
对年份 t、死因 c：
`share[t,c] = D[t,c] / D_all[t] × 100`。

- 分子：按同一死因汇总所有目标年龄及男女的 Deaths Number。
- 分母：同样年份、年龄、性别范围的官方 All causes 死亡人数。
- **以 19 类死亡数加总作分母只能算 19 类内部占比，不能冒充原文 Figure 1。**

## 代码分步说明
运行 [run.R](run.R)。
1. `subset()` 只保留 Number。
2. `aggregate(val ~ year + cause_name)` 把六个年龄组与男女加总。
3. 用 1980–2015 年的死亡数确定九个候选主要类别，不用测试期来挑选。
4. `xtabs()` 转为年份 × 死因矩阵，`rowSums()` 计算加总。
5. 必须先有 `data/raw/gbd_all_causes.csv` 才可计算 `All other causes` 并用 `polygon()` 绘制正式比例面积图；缺文件时明确跳过作图。

## 已核对的结果
原始表中 2019 年 60–89 岁 19 类死亡人数合计约 99,182，心血管疾病约 47,604。分母不是 All causes，所以**不能**直接与原文“九类覆盖约 95% 的全部死亡”比较。

## 与原文的差异
死因来自 GBD 分组而非原文 ICD 章节，且缺少 90+；COVID-19 相关死因类别可能不同。正式图计算完再补充图中实际趋势与原文的比较，不预填结论。
