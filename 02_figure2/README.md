# 02｜Figure 2：年龄标准化分死因死亡率（原文 §3.1）

## 原文内容
Figure 2 按男女分别展示分死因年龄标准化死亡率的时间变化。原文采用 1970 年人口年龄结构作为固定标准权重。

## 计算公式
`ASMR[t,c,s] = Σ_x w[x,s] × m[x,t,c,s]`，其中权重之和为 1。

- `m`：该年龄组、年份、死因、性别的死亡率。GBD Rate 单位一般是每 10 万人。
- `w`：固定标准人口年龄权重；不能每年变动。
- 使用 1980 年人口作为参考时，与原文 1970 年权重不相同，必须在结果表中注明。
