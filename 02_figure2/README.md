## 3. 计算公式

年龄标准化率：

\[
ASMR_{t,s,c}=\sum_x w_x\frac{Rate_{t,s,c,x}}{100000}.
\]

固定权重采用 1980 年两性人口合并分布：

\[
w_x =\frac{P_{x,1980,\mathrm{Male}}+P_{x,1980,\mathrm{Female}}}
{\sum_a(P_{a,1980,\mathrm{Male}}+P_{a,1980,\mathrm{Female}})}.
\]

GBD 的年龄别 Rate 已经包含人口分母；不能**再除以人口一次**。额外人口数据主要用于计算固定权重和检查 Number/Rate 是否一致。

## 4. 如何运行和验证

在 RStudio 打开更新后的 `run.R`，点击 **Source** 运行整份脚本。或者在控制台运行：

```r
source(file.choose())  # 第一次选择 Figure 2 的 run.R 程序本身
```

接下来会依次弹出两个选择窗口：① 选择 Population CSV；② 选择 Deaths CSV。**不要求任何固定输入目录或文件名。** 注意若使用控制台逐行执行，应从脚本最上方开始，以免跳过两个 `file.choose()`。输出仍按项目相对路径写入 `outputs/02_figure2/`。

依次完成：
1. 检验 Population 528 行全部数据：地区、年份、年龄、性别、Population/Number、重复、缺失、区间。
2. 使用 1980 年 12 行构造六个权重并检验总和为 1。
3. 检验 Deaths 20,064 行、19 类死因、Number/Rate 的完整性。
4. 将死亡数据与独立人口按 **year + sex + age** 配对，对每个死因计算 **Number / Population × 100000**，并与下载的 Rate 比较；输出逐行差异表。
5. 用人工质量警戒阈值筛查：中位相对差异 >2% 或第 95 百分位相对差异 >10% 则停止。阈值不等于统计检验；GBD 分别报告的估计均值也可能不完全满足比值恒等式。
6. 计算 19 死因 × 2 性别 × 44 年 = **1672** 条 ASMR；每一个标准化率应在相应六个年龄别死亡率的最小值和最大值之间。
7. 用训练期（1980–2015）死亡人数选九类 GBD 死因，绘制原文风格的 3×3 面板图（男性实线、女性虚线），但**并非原文九个 ICD 章节的逐项复制**。

## 6. 后续解释的注意事项

- 比较各死因趋势、男女差异、拐点；不要仅依据 ASMR 变化推断因果机制。
- GBD 死因组不等于原文九个 ICD 章；年龄截断不同（缺少 90+）、标准人口年不同（1980 对 1970），因此 ASMR 绝对值并不可直接比。
- GBD Population 是人口估计，不应称作 HCSO 真实登记中央暴露量。
- 死因预测的后续模型需要检查全年龄×年份死亡数与暴露量的匹配和分布假设，不能凭 Figure 2 的权重直接当作已满足所有建模条件。
