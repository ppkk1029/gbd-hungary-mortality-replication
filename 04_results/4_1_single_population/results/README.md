# §4.1｜单人口模型的拟合结果（用于 §4.2）

这里只保留 2026-11-10 使用 R 对 **GBD** 数据重新估计的单人口模型参数与时期因子，而不是 §4.2 的聚类结果。

- `kappa_all_models.csv`：7 种模型 × 9 种 GBD 死因 × 男女 × 各模型因子；是 §4.2 的正式输入。
- `parameters_all_models.csv`：单人口模型估计的年龄参数。
- `fit_diagnostics_all_models.csv`：拟合收敛检查。

这三份数据以前位于 §4.2 文件夹，现按论文流程归入 **§4.1**。它们来自同一套先前核验过的单人口 R 拟合，没有因为后续聚类算法修订而改变。

数据边界：GBD 估计死亡人数/代理暴露量、1980–2015、6 个五岁年龄组、9 个 GBD cause level-2 类别；不等同于作者 HCSO 1970–2021 的 ICD 原始数据。它们不是本次重新执行 126 组拟合得到的结果。原始 GBD D/E 文件没有上传。

后续 R 脚本直接以此处 `kappa_all_models.csv` 计算新的 DTW 和全部七项 CVI，无需误用旧聚类数。
