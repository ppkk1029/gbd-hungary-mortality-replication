# 00｜数据检查：GBD Level 1 与 Level 2

## 为什么核对
论文 Figure 1 的百分比分母是**全部死因死亡人数**。用户下载了相同版本的 GBD 2023 Level 1（三大类）和 Level 2（19 个有老年分年龄结果的主要死因组）。需要证明这 19 类加起来是否已覆盖全部死亡。

## 输入
将两个原始 CSV 放在仓库根目录下的 `data/raw/`：
- `IHME-GBD_2023_DATA-b40ffc46-1.csv`：Level 2，20,064 行
- `IHME-GBD_2023_DATA-97ee48e8-1.csv`：Level 1，3,168 行

不修改原始文件；数据不提交公开仓库。

## 一步一步的核验方法
运行 [check_level1_level2.R](check_level1_level2.R)：

1. `read.csv()` 读入两张数据表；
2. `aggregate(val ~ year+sex_name+age_name+metric_name, FUN=sum)` 在每个相同单元内分别加总 Level 1 三类、Level 2 十九类；
3. `merge()` 按年、性别、年龄、Number/Rate 对齐；
4. 做 `Level1-Level2` 差额并核对绝对值小于 `1e-6`；
5. 仅对 `Number` 跨年龄与性别求和，并保存逐年核对表。

**不可把不同年龄组的 Rate 简单相加称为总死亡率**；这里只是在同一年龄组核验同层级死因率的加法一致性。

## 实际核验结果（2026-11-09）
- 两份数据各覆盖 1980–2023 年、两个性别和六个五岁年龄组。
- 528 个 `Number` 单元、528 个 `Rate` 单元全部核对通过，共 1,056 组。
- 最大绝对差异为 `1.8189894e-11`，属于浮点运算精度。
- 2019 年 Level 1 三大类合计 = Level 2 十九类合计 = **99,182.02771**（60–89 岁，男女合计）。
- 2021 年两者合计均为 **119,215.70307**。

**结论：在这批实际下载数据的目标年龄范围，19 个 Level 2 类别已完整覆盖全部死亡人数。** 之前以为还缺 `All causes` 分母的判断已被数据核验纠正。

## 与原文不同的地方
原文 HCSO、1970–2021、九类 ICD、包含 90+；本项目 GBD、1980–2023、19 类原生 Level 2、只到 85–89。核对成功仅代表下载数据内部一致，不等于它与 HCSO 数值相同。
