# 00｜数据检查（原文 §3 数据准备）

## 这一步为什么做
先验证原始 CSV 是否具有完整的年龄 × 年份 × 性别 × 死因记录。完整的数据是估计时期因子与 DTW 聚类的前提。

## 输入
`data/raw/IHME-GBD_2023_DATA-b40ffc46-1.csv`，保留原始文件，不手动修改。

## 运行步骤及代码解释
运行 [check_data.R](check_data.R)。

1. `read.csv()` 读取 CSV。
2. `dim()`、`unique()`、`table()` 查看维度与 Number/Rate 数量。
3. `setdiff(1980:2023,unique(gbd$year))` 核对中间是否缺年份。
4. `duplicated()` 检查同一年、年龄、性别、死因及计量方式是否重复。
5. `is.na()` 与 `val/lower/upper` 比较缺失、负数和不确定性区间。
6. `stopifnot()`：数据不符合预期时停止，而不是继续计算。

## 已核对结果
- 20,064 行、18 列。
- 1980–2023 连续 44 年、两个性别、六个五岁年龄组、19 类死因。
- Number 10,032 行，Rate 10,032 行；缺失、重复观测和负值均为零。

这些结果只说明**结构完整**，不等于 GBD 估计没有误差，也不等于原文 HCSO 数据。

## 必须理解的概念
Number 是死亡人数估计；Rate 是每十万人口的死亡率。Figure 1 使用死亡人数构成，Figure 2 使用年龄标准化死亡率，因此不额外增加原文没有的独立教学图表。

## 与原文差异
原文 1970–2021、HCSO 单岁年龄及 90+ 合并；本项目 1980–2023，60–89 岁六个五岁组。不能要求图表数值完全一致。
