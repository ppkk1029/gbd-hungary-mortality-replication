# 03｜单人口死亡率模型

## 原文研究问题
对于每种死因和每种性别，分别建立死亡率模型，提取随年份变化的时期因子。

## 本章应记录
1. 原文实际使用的各模型、公式、参数和识别约束。
2. 对应的 R 实现，代码逐段解释。
3. 估计得到的年龄效应与时期因子。
4. 原文实际报告的拟合评价指标和表格。
5. 模型结果与原文的异同以及可能原因。
